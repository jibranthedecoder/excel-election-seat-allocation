Calculation workflow

How the result is calculated

  1. Import candidate vote data.
  2. Group candidates by party or list.
  3. Calculate total votes for each group.
  4. Rank candidates inside their party by personal votes.
  5. Calculate comparative figures.
  6. Sort all candidates by comparative figure and select the top 20.

Formula

D'Hondt comparative figure

comparative figure = party total votes / candidate rank inside party

This fixes the common mistake of dividing each candidate's own personal votes by 1, 2, 3, and so on.
