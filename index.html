Spreadsheet-based analysis for calculating elected candidates from vote data. The project focuses on sorting, grouping, comparative figures, ranking, and presenting election results clearly.

Calculation workflow

How the result is calculated

  1. Import or list candidate vote data.
  2. Group candidates by party or list.
  3. Calculate total votes for each group.
  4. Generate comparative figures for candidates.
  5. Sort all candidates by comparative figure.
  6. Select the top candidates according to the number of seats.

Project focus

What this demonstrates

  1. Handling a larger dataset in a spreadsheet.
  2. Using sorting and ranking logic.
  3. Connecting calculations to visual result interpretation.
  4. Documenting assumptions and calculation method.
  5. Turning an Excel task into a presentable data-analysis project.
